# AniTV 原生版 1.0

Android TV 原生番剧客户端。采用 BT 风格的深色侧栏、紧凑网格和粉色焦点边框，代码与资源独立实现，没有使用 BT 反编译源码。

包名 `tvx.anich.preview`，Android 8.0+，与现有 `tvx.anich` 共存。当前版本 `1.0`（versionCode 30108）。

1.1 审查修订（30107）：删除重复的弹窗返回分支；倍速参数拒绝与播放器状态失效分别处理，状态失效后不继续启动；选集弹窗同步沉浸式标志，单集分段显示单个编号；播放设置首次定位当前倍速，随后在本次播放中记住上次焦点。

1.1 交互与传输优化（30106）：快进显示短时目标时间浮层，返回提示 5 秒退出窗口；菜单键打开倍速/画面比例设置，下键仍切线路。长篇选集按 50 集分段并可跳到最新。索引侧栏右键进入筛选，筛选下键恢复浏览位置；回看前段复用有效缓存。MP4 顺序读取按 2 MiB 请求窗口复用连接，缓存仍最多四个 512 KiB 块。

1.1 焦点修复（30105）：索引仅接近底部才预加载下一页；不积压长按方向事件；返回详情按番剧 ID 和原屏幕位置恢复。索引按菜单键可直接聚焦类型 / 语言 / 年份筛选栏。

推荐、索引、搜索、详情和登录后的按编号播放均使用当前 AniCh 服务。索引按类型、语言、年份筛选，搜索按关键词查询，翻页使用上一页最后一个 AniCh ID。共享正常登录会话；目录拒绝会话时会提示在设置登录或重新登录。

Preview 18 已完成原版请求结构核对及本地接口/界面回归。按用户要求，电视实测由用户完成；尚未将本次登录状态下的真实目录结果标记为已通过。旧版本的公共目录网络问题记录保留于 [VERIFICATION-v6.md](VERIFICATION-v6.md)，新版目录不再请求该服务。

## 当前范围

- 原生侧栏、海报列表、类型/语言/年份筛选、搜索、详情简介、本机收藏。
- RecyclerView 复用、后台解析和缓存、分页去重与停止条件、取消过期请求。
- 图片按卡片实际像素尺寸解码，内存资源缓存 16 MiB、位图池 8 MiB、磁盘图片缓存 64 MiB。这些不是应用总内存上限。
- 接口错误、403 网页验证、超时与重试都有明确状态，失败时保留已展示的列表。
- 原生剧集选择、线路切换、MP4/HLS 播放、观看进度恢复，以及可选的自动下一集。当前 AniCh 剧集与线路支持字符串选集、JSON 字节数组包装的 protobuf 和线路标识。自定义接口保留旧版编号调用。
- MP4 优先使用 MediaDataSource + NuPlayer，以保留 v1.9 在该海信电视上的播放适配；HLS 使用 Media3。播放器的 HTTP 分段缓存最多四个 512 KiB 块；相邻块在同一 2 MiB 请求窗口内按需读取，不增加预取线程。忽略 Range 的 HTTP 200 响应保持连续读取；跨出缓存后的随机跳转仍需要顺序跳过数据，速度取决于服务器。
- 设置中的“播放视频链接”可以直接打开有权访问的 HTTP/HTTPS 视频流。
- 与 v1.9 独立保存账号、收藏和历史；当前原生版本可覆盖此前预览版并保留其数据。

首次启动默认加载真实推荐。正式包不开放演示模式和旧版应用跳转；本地演示数据只可在 Debug 构建中通过测试 Intent 启用，忽略旧版保存的演示偏好。

## 遥控

| 操作 | 行为 |
| --- | --- |
| 侧栏上/下 | 逐项移动，不绕回 |
| 侧栏确认 | 切换分页；推荐/索引长按确认 2 秒刷新，并让剧集缓存失效 |
| 侧栏右 | 当前索引页进入筛选栏，其他当前页进入内容；其他按钮不切页 |
| 卡片左/右 | 同一行内移动；首列左键回到当前侧栏；末列右键不跨行 |
| 卡片上/下 | 保持列移动；末行不跳到其他控件 |
| 首行上 | 有前段时回看前段，否则进入筛选栏；菜单键可直接到筛选栏 |
| 筛选栏左/右 | 依次移动；最左侧左键回侧栏 |
| 筛选栏下 | 恢复当前浏览位置 |
| 确认卡片 | 打开详情 |
| 详情返回 | 恢复原列表位置和卡片焦点 |
| 首页返回 | 先回当前侧栏；侧栏内两秒双返回退出 |

长按方向键限速到约 90ms 一步。下一行尚未布局时等待卡片挂载后再请求焦点，避免退回系统几何焦点搜索。

播放时：确认暂停/继续，左右单按快退/快进约 10 秒；持续按住 1 秒后每步 30 秒，3 秒后每步 60 秒，松开后重置，上键选集，下键换源，菜单键打开右侧播放设置（1× / 1.25× / 1.5× / 2×、适应 / 裁剪铺满 / 拉伸），第一次返回隐藏进度条并提示退出窗口，5 秒内再按一次返回番剧介绍页；超过 5 秒重新计为第一次；其他播放操作会重置退出步骤。选集/线路窗口取消后恢复先前的播放状态；换源保留当前集进度。快进/快退显示目标时间小浮层，停止操作 1.5 秒后隐藏，播放时仍不显示整个进度条。长篇选集每段 50 集；从首行按上可进入分段/跳到最新，切段不触发播放或额外接口请求。倍速与画面比例保存在本机，切集、切线和重新打开时继承；暂停修改倍速不会恢复播放。快进位置受关键帧影响。自动下一集在设置中开启，默认关闭。

播放器将“希望播放/暂停”的用户状态与实际缓冲状态分开保存，避免 HLS 快进缓冲时把暂停误判为继续。退出或退到后台会保存进度并释放播放器，不在后台继续播放。

登录页允许投屏和外接键盘输入，密码保持掩码显示且不保存。

## 在线数据

- AniCh 默认根地址从 1.5.27 APK 的实际默认值核对：`https://eo.api.anich.sends.eu.org.cdn.cloudflare.net`。公开仓库 `api.json` 的旧域名已过时；保存为旧默认域名的预览版会自动迁移。
- 推荐：`GET /bangumi/recommend`。当前响应包含分组 `data[].list[]`，扁平化并按 ID 去重；实测返回 120 部。
- AniCh 详情：`GET /bangumi/detail/{id}`，JSON。
- 可匿名访问的选集：`GET /vod/episode?title=...`，返回字符串数组。按实际集名保留请求标签，普通集数按数值排序，特别篇保留独立标识。
- 可匿名访问的线路：`GET /vod/get?title=...&episode=...`。当前 JSON 数字数组先还原为 protobuf，随后解析播放 URL、集名和线路标识。线路请求允许 60 秒总超时，可随页面退出取消。
- 索引：`GET /bangumi/list?skip=...&type=tv|movie|ova&lang=ja|zh|en|ko|other&year=...`。空筛选不发送；`skip` 首次为 0，之后为上页最后一个番剧 ID。
- 搜索：`GET /bangumi/search?keyword=...&skip=...`，不混入索引筛选条件。结果保留 AniCh ID，直接进入同服务详情和按编号取源。
- 列表支持原 protobuf、JSON 数字数组包装 protobuf、JSON 列表；解析标题、海报、更新集数，忽略未知字段。空页、重复页停止加载，服务端错误不能显示成成功的空结果。
- 早期版本保存的 Bangumi 收藏仍保留独立 ID 空间及旧详情读取兼容，新索引/搜索不会再生成这些编号。
- POST 缓存键包含请求方法、URL 与请求体，避免不同筛选条件读到同一份缓存。
- 自定义 HTTPS 根地址使用原兼容协议的索引/搜索、剧集和播放路由，方便保留既有接口及受控测试环境。

已支持正常账号登录；登录后的 AniCh 条目使用 `/bangumi/episodes/{id}` 的官方 `sort` 集数，再以 `/vod/{id}/{sort}` 一次获取完整线路。跨季连续编号必须保持，例如《药屋》第三季从 49 开始。匿名/公共目录条目保留标题查询，部分标题可能没有可播放线路。详见 [完整线路说明](SOURCE-COMPLETION.md)。

验证依据：公开 AniCh 1.0.0 protobuf 定义、1.5.27 的请求结构与实际匿名响应，以及 [Bangumi v0 API schema](https://github.com/bangumi/api/blob/master/open-api/v0.yaml)。真实线路会过期，未把带完整地址的媒体响应提交到仓库。

## 构建

需要 JDK 17+、Android SDK Platform 35 / Build Tools 35，以及能访问 Google Maven / Maven Central 的网络。

```sh
export JAVA_HOME=/path/to/jdk
export ANDROID_HOME=/path/to/android-sdk
./build-native.sh
```

脚本默认生成不可调试的 Release APK，首次创建项目内的签名，密钥保存在 `signing/native-preview-debug.keystore`（Git 忽略），之后复用以便保留预览版数据。沿用原生预览版的本地签名以支持覆盖升级；它不是 v1.9 发布签名。不要删除需要继续使用的签名文件。

默认产物：`app/build/outputs/apk/release/app-release.apk`。正式版记录见 [RELEASE-1.0.0.md](RELEASE-1.0.0.md)。

```sh
./build-native.sh assembleDebugAndroidTest
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell am instrument -w tvx.anich.preview.test/androidx.test.runner.AndroidJUnitRunner
```

测试覆盖 protobuf/JSON 数据、异常响应、分页、播放地址解码和分段读取，以及真机方向键的跨行、边界、筛选栏和详情返回。

播放真机测试需要先生成测试素材（自行生成测试图案和正弦音，不下载第三方影视内容），然后重新构建测试 APK：

```sh
FFMPEG=/path/to/ffmpeg tools/generate-playback-fixtures.sh
./build-native.sh assembleDebug assembleDebugAndroidTest
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell am instrument -w -e class tv.anitv.PlaybackDeviceTest,tv.anitv.RemoteNavigationTest tvx.anich.preview.test/androidx.test.runner.AndroidJUnitRunner
```

测试素材和服务只打包在测试 APK 内，不进入应用 APK。测试服务器提供 MP4 Range、HLS 和模拟剧集/线路接口，覆盖详情到播放、暂停、快进、换源保留进度、换集和页面重建恢复。该模拟接口不是对 AniCh 线上授权校验的绕过。

设备截图分别写入预览版 external files 的 `evidence/` 和 `playback-evidence/` 目录。海信硬件视频层可能不进入 ADB 截图；首帧事件与音轨识别日志不等于用户人工确认画面和声音正常。

旧版公共目录的独立诊断检查（不代表 preview18 的默认目录路径，会连接公共目录和 AniCh，并读取少量视频分段）：

```sh
./build-native.sh testDebugUnitTest -PliveApi=true --tests tv.anitv.LiveApiTest
```

本次结果详见 [VERIFICATION-v5.md](VERIFICATION-v5.md)。

推荐/索引及剧集缓存默认有效 12 小时；推荐/索引命中有效磁盘缓存不额外请求网络。短按推荐/索引只切页，当前页短按不刷新；长按确认 2 秒刷新当前页，同时使剧集内存/磁盘缓存失效，下次打开番剧时更新选集，不批量预加载。刷新保留当前画面，数据返回后替换；继续翻页仍按需取下一页。图片磁盘缓存不设固定时效，按 64 MiB 容量淘汰。剧集内存缓存仍最多 8 部、合计 2000 集。
