# AniTV 1.1（30136）

安装包文件名为 `AniTV-1.1-30136.apk`，包名为 `tvx.anich.preview`，支持 Android 8.0 及以上。与 30135 使用同一签名，可覆盖安装并保留本地数据。

- 缓存写入和清理在后台执行，界面提交缓存时无需等待写盘锁。
- 续播进度按接口区分并迁移旧记录。同一编号曾在多个接口出现时，旧进度归到观看历史中最近使用的接口。
- 自动下一集读取剧集失败时重试一次，按返回或重播可取消待切集。
- 首次播放静默选择默认线路。线路超时从当前进度切换，当前列表中的线路最多自动尝试一轮。
- 收藏与历史均支持菜单键多选，移除收藏保留观看记录和进度。
- 播放器返回提示简化为「再按一次返回退出播放」。

本地验证通过 267 项单元测试，跳过 1 项可选联网测试。Release 构建、Lint、设备测试源码编译和签名校验通过。
